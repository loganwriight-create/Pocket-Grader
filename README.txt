POCKET GRADER — GITHUB PAGES PACKAGE

PUBLISH:
1. Create/open your GitHub repository.
2. Upload the CONTENTS of this folder (not the folder itself) to the repository's main branch.
3. Make sure index.html is in the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch: main; folder: /(root); then Save.
7. Wait for GitHub Pages to publish, then open the URL shown on the Pages screen.

ADD TO IPHONE:
1. Open the published HTTPS website in Safari.
2. Tap Share, then Add to Home Screen.

NOTES:
- This package adds a web app manifest, app icons, and a service worker for basic offline caching.
- Camera access requires HTTPS (GitHub Pages provides HTTPS).
- The pre-grade score is a user-guided estimate based on selected condition ratings and centering; it is not automated AI image grading or an official PSA/BGS/ACE/CGC grade.
- Sold-price research opens eBay completed/sold listings; live eBay sales data is not integrated.
